# Brag Plan: AI Interview Prep Kit

## What is this app?
Paste a job posting and company URL → get an editable interview prep kit: crawled research, category questions, flashcards, deterministic coverage, and an exact-day schedule you can practise against.

## The angle
Neo-brutalist “paper dossier” energy — cream stock, hard black shadows, a kit that *refuses* to lie. The punchline is the honesty contract: the model drafts; code owns the schedule and coverage. Not “AI magic” — a prep plan you can defend in the interview itself.

## Hook (first 2-3 seconds)
Giant type SLAM: **“A prep plan that won’t gaslight you.”** Hard shadow snap on the paper background. Earns curiosity because every other interview tool oversells the model.

## Key moments (the middle)
- **Kit dossier rebuild** — Senior Backend Engineer card: coverage meter fills to Clear, Weak spots chip (“1 must-have open”), Sources (“3 pages used”) pop in sequence.
- **Pipeline checklist** — steps tick one by one (crawl → questions → coverage gap pass → schedule), then **Check passes: 2** lands hard.
- **Practice flashcard flip** — dark card flips to reveal answer; ratings 1–5 row; least-confident-first badge.

## Outro / punchline
Product name locks: **Prep Kit** · *Turn a posting into a defensible prep plan.* · Free locally with Ollama — no API key.

## User flow worth showing
1. Entry — landing hero + Create account CTAs (paper UI).
2. Key action — generate pipeline: requirements → crawl → questions → coverage close → schedule.
3. Result — editable kit: coverage Clear, practice card, day grid 1–5.
